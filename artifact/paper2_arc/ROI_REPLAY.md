# Same-image ROI and physical safety replay

This is an artifact-only supplement: no manuscript or new board execution is
required. It preserves the distinction between historical checksum-only
campaigns and the September 25 raw-byte captures below.

## Commands

From the artifact repository root, with its standard NumPy/PyYAML dependencies:

```
python -B scripts/paper2_conventional_comparison_v1/replay_physical.py
python -B scripts/paper2_conventional_comparison_v1/replay_safety.py
```

These commands are read-only and location independent. Historical absolute
machine paths in provenance records are not used. The original confirmation
analyzer and launch protocol remain archived, but public replay uses a compact
NumPy-only dense oracle; PyTorch, trained-model compiler, FPGA tools and boards
are unnecessary. Bounded float64 integer sums are exact and separately checked
against INT64 halo convolution at edges/interior. The own-trained W24 integer
weights are supplied, not a training checkpoint or a third-party model.

The publication table is generated by `src/report/paper2_roi_publication.py`.
Run it in a disposable copy or specify external `--json-output`/`--tex-output`
paths so the exact-inventory release is not modified. The one-command artifact
runner already uses an external disposable copy and verifies output hashes.

  rebuild or a vendor-IP redistribution.

## Findings and boundaries

Equal-mask mean request-to-selected-residual-publication service was 114.874 ms
for full raster, 103.476 ms for one outer box, and 96.157 ms for merged regions.
Merged regions reduce that mean by 16.29% versus full raster and 7.07% versus
outer box. Merged versus outer regresses on 5/15 sparse masks, up to 1.084%.
The empty and dense controls remain separate, all regressions are retained,
and six repeats in one board session do not establish population generality.

Timing includes planning, packing, DMA, FPGA execution, private scatter, cache
maintenance and software publication. It excludes rendering, reconstruction
and display. The FPGA deadline endpoint precedes later CPU publication; the
performance test disables deadlines. Safety smoke corroborates selected fault
paths, not arbitrary concurrent readers, complete display deadlines or formal
proof. Conventional ROI cropping is established, not a new algorithm, and
same-image modes do not show an area or energy advantage.

Earlier engineering P001/P002 capture-wrapper faults and unlaunched P004
preparation are documented in the engineering ledger. P002's numerical
qualification passed after recovering its already-completed run; P003 had a
clean terminal/capture path. No older results were overwritten or relabeled.
